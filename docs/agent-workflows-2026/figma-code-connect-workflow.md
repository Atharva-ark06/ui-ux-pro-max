# Figma Code Connect Workflow


1. Identify design components used in the selected frame.
2. Find their production-code equivalents.
3. Review suggested mappings rather than accepting them blindly.
4. Confirm props and variants correspond to real implementation behavior.
5. Test generated code against the design system.
6. Update mappings when components change.

Mappings improve component reuse but do not replace code review or responsive and accessibility tests.

Official: https://developers.figma.com/docs/figma-mcp-server/
