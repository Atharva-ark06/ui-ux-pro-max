# Figma Slides and FigJam with AI Agents

When a client supports Figma MCP tools for Slides or FigJam, use a separate workflow from production UI implementation.

## FigJam
- Define the question the board should answer.
- Group related ideas into labeled sections.
- Use connectors to show actual relationships.
- Mark assumptions, decisions, and unresolved questions separately.
- Confirm that the diagram is readable at presentation scale.

## Slides
- Start with audience, objective, and key message.
- Give each slide one clear purpose.
- Maintain consistent hierarchy and typography.
- Use charts only when data and sources are verified.
- Check alignment, density, and text legibility.

## Safe editing
Prefer a new draft or a clearly scoped target. Confirm before overwriting shared content. Review the resulting board or deck instead of trusting the generation step alone.
