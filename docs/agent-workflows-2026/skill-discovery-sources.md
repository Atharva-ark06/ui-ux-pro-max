# Trusted Skill Discovery Sources

Prefer official documentation and maintained repositories.

## Primary sources
- Claude Agent Skills: https://platform.claude.com/docs/en/agents-and-tools/agent-skills/overview
- Claude Code skills: https://docs.anthropic.com/en/docs/claude-code/skills
- Codex skills: https://developers.openai.com/codex/skills/
- OpenAI Codex repository: https://github.com/openai/codex
- Agent Skills standard: https://agentskills.io/
- Figma MCP: https://developers.figma.com/docs/figma-mcp-server/
- MCP specification: https://modelcontextprotocol.io/

## Discovery steps
1. Start with official docs.
2. Read the repository README and license.
3. Verify supported client and version.
4. Inspect maintenance and known issues.
5. Read the skill instructions and scripts.
6. Check for duplicate skills.
7. Test safely and record provenance.

A popularity metric is not a security review. Do not install a large collection without understanding the purpose, permissions, and dependencies of each skill.
