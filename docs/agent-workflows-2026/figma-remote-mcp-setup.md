# Figma Remote MCP Setup


Figma recommends its hosted MCP endpoint for most supported clients: https://mcp.figma.com/mcp

1. Check the current Figma MCP client catalog.
2. Add the remote server through the client-specific setup guide or plugin.
3. Authenticate with the Figma account when prompted.
4. Confirm the connection and available tools.
5. Start with a specific frame or file link.
6. Verify output against the source design.

Tool availability and write access depend on client, plan, seat, and current Figma rules.

Official: https://developers.figma.com/docs/figma-mcp-server/remote-server-installation/
