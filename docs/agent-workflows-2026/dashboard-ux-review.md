# Dashboard UX Review

Dashboards should make the important state and next action easy to identify.

## Information hierarchy
- Lead with the user's primary question, not a wall of metrics.
- Label units, time ranges, and comparison periods.
- Distinguish zero, unavailable, stale, and loading data.
- Use chart types that fit the comparison or trend.
- Provide meaningful empty and error states.

## Interaction
- Filters should be visible and explain their scope.
- Drill-downs should preserve context and provide a clear way back.
- Tables need usable sorting, labels, and responsive behavior.
- Color should not be the only way to distinguish series.

## Validation
Check data accuracy, keyboard access, small-screen behavior, loading latency, and whether a user can explain the main insight after a brief scan.
