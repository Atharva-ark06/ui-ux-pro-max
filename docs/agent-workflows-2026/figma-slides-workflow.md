# Figma Slides Workflow


1. Define audience and the one message each slide should convey.
2. Gather source material and verify data claims.
3. Establish a consistent layout and typography system.
4. Keep text legible and avoid overfilled slides.
5. Use charts only with traceable data and labeled units.
6. Review the deck at presentation size.
7. Confirm the output and obtain approval before sharing externally.

Official: https://developers.figma.com/docs/figma-mcp-server/tools-and-prompts/
