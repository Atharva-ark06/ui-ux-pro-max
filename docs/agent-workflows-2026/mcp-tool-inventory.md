# MCP Tool Inventory Template


For each connected server, record:
- Server name and trusted source
- Purpose and owner
- Authentication method and scopes
- Read-only and write-capable tools
- Sensitive data accessed
- External side effects
- Rate limits and failure behavior
- Revocation and incident contact

Revisit the inventory after server updates or permission changes. Remove unused servers and tools.

Reference: https://modelcontextprotocol.io/
