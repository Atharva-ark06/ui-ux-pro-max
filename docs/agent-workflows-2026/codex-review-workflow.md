# Codex Review Workflow


1. State the risk areas and acceptance criteria.
2. Inspect the full diff and surrounding code.
3. Check correctness, authorization, data handling, and error paths.
4. Run relevant tests when possible.
5. Report findings with file/line references and reproducible impact.
6. Separate confirmed defects from questions and style suggestions.

Never claim a test passed unless it was actually run.

Official: https://developers.openai.com/codex/
