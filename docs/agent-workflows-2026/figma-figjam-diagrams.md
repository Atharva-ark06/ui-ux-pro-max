# FigJam Diagram Workflow


Before generating a diagram, define the audience, question, node types, relationships, and expected level of detail.

Use consistent labels, meaningful connectors, and clear groupings. Mark assumptions and unresolved decisions distinctly. After generation, inspect layout, edge crossings, missing relationships, and readability at presentation scale.

Do not let a generated diagram imply that an unverified relationship is a fact.
