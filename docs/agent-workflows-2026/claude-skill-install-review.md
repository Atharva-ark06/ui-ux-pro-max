# Claude Skill Installation Review


Before installing a skill, verify its source, intended client, supported file structure, license, and any scripts or external dependencies.

After installation, restart or reload the client if the docs require it. Confirm discovery and test the skill on a representative task. Also test a task outside its intended scope.

Avoid installing unknown shell scripts or granting broad access simply because a skill is popular.

Official: https://docs.anthropic.com/en/docs/claude-code/skills
