# Data Visualization Review Checklist

## Purpose and encoding
- [ ] The chart answers a specific question.
- [ ] The chart type matches the task: comparison, distribution, relationship, or trend.
- [ ] Axes, units, legends, and time ranges are explicit.
- [ ] Scales do not exaggerate or hide differences.
- [ ] Missing values and uncertainty are explained.

## Accessibility
- [ ] Series are distinguishable beyond color alone.
- [ ] Labels and legends are readable.
- [ ] A text summary or data table is available when needed.
- [ ] Keyboard and screen-reader access are considered.

## Integrity
- [ ] Data source and update time are documented.
- [ ] Aggregation and filtering are transparent.
- [ ] The visualization does not imply unsupported causation.
- [ ] Values shown in the UI match the underlying data.

Review the chart with realistic values and edge cases, including empty, negative, and unusually large values when relevant.
