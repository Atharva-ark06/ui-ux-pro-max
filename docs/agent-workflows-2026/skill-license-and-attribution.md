# Skill License and Attribution Guidance

A skill's instructions, scripts, examples, and included assets may have different licensing terms.

## Before reusing a skill
1. Find the license in the source repository and skill directory.
2. Check whether the license covers the files you intend to copy.
3. Preserve required copyright and attribution notices.
4. Review restrictions on redistribution and modification.
5. Track local changes and the upstream source.
6. Avoid copying assets whose license is unclear.

## For repository maintainers
Record the source URL, license, review date, and any local modifications. Do not assume that a public GitHub repository means every file is unrestricted for reuse.

## When uncertain
Prefer linking to the original source or writing an original implementation from documented behavior. Ask a qualified reviewer when licensing implications are material.
