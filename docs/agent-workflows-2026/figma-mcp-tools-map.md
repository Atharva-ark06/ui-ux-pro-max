# Figma MCP Tool Categories


Figma MCP tools can support reading design context, writing native canvas content, downloading assets, mapping code components, and generating diagrams or design layers.

Choose the workflow by outcome rather than memorizing tool names. Check the current tool reference because availability can differ between remote and desktop servers.

The agent still needs clear instructions, a component system, and verification; the MCP connection alone does not guarantee production-ready code.

Official: https://developers.figma.com/docs/figma-mcp-server/tools-and-prompts/
