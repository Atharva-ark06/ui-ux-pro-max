# Claude Plugin Anatomy


A plugin may bundle reusable skills, commands, hooks, subagents, and connectors depending on the supported host.

Review each part independently:
- Skills: task instructions and resources.
- Hooks: automated actions on supported lifecycle events.
- Subagents: delegated tasks and their tool permissions.
- Connectors: external service access and authentication.

Install only the pieces needed for the workflow and check which features are supported in your chosen Claude surface.

Official: https://support.claude.com/en/articles/13837440-use-plugins-in-claude
