# Codex Skill Authoring


A maintainable skill explains when it applies, what outcome is expected, and a reliable workflow to get there.

Checklist:
- Use a clear, specific skill name and description.
- Keep the main instructions focused; move detailed references into linked files.
- State prerequisites and required inputs.
- Include verification and failure handling.
- Avoid broad, unrelated responsibilities.
- Test triggering, non-triggering, missing-input, and failure cases.
