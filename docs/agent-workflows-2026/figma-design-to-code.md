# Figma Design-to-Code Workflow


1. Link the exact frame or selection.
2. Identify the target framework and existing component library.
3. Inspect variables, spacing, typography, and component instances.
4. Map design elements to existing components before creating new ones.
5. Implement responsive and interactive behavior, not only static appearance.
6. Compare screenshots at matching viewports.
7. Run functional and accessibility checks.

Treat generated code as a starting point and verify it against the actual design.

Official: https://developers.figma.com/docs/figma-mcp-server/
