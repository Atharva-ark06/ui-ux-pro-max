# UX Writing Review Checklist

UI text should help people understand the task, make a decision, and recover from errors.

## Review dimensions
- Clarity: use familiar words and specific actions.
- Concision: remove repetition without removing essential context.
- Consistency: use the same term for the same concept.
- Tone: respectful, direct, and appropriate to the product.
- Accessibility: avoid relying on color, position, or ambiguous phrases.
- Localization: allow for text expansion and avoid concatenated fragments.

## Error messages
A useful error explains what happened, what the user can do next, and whether their work was saved. Avoid exposing stack traces, secrets, or internal system details.

## Review procedure
Read each label in context, check button text out of context, inspect empty and error states, and test whether instructions remain clear on mobile. Confirm product terminology with the team instead of inventing synonyms.
