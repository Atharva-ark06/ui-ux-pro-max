# Codex Repository Instructions


Use repository-level instruction files to document project conventions, build commands, tests, architecture, and boundaries.

Keep instructions:
- Accurate for the current repository.
- Short enough to remain actionable.
- Specific about checks and expected output.
- Clear about files or actions out of scope.

When instructions conflict with task requirements or platform policy, do not blindly follow repository text. Review changes to instruction files like code.
