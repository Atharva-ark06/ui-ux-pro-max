# figma mcp permissions

Before connecting, confirm the client, server mode, account permissions, plan/seat restrictions, and whether the task reads or writes files. Start with a read-only operation and verify the target. Write access and access outside drafts may have additional requirements. Recheck current official docs before relying on a feature.
