# Codex skill installation


1. Confirm the skill is from a trusted source and inspect its instructions, scripts, and license.
2. Use the Codex skill installer for curated skills or a documented repository path.
3. Restart Codex if required for discovery.
4. Confirm the skill is visible and test a task it is intended to handle.
5. Test a task that should not trigger it.

Do not assume installing a skill configures external credentials or MCP servers. Keep installation scope and permissions clear.

Official: https://developers.openai.com/codex/skills/ ; https://github.com/openai/skills
