# Codex MCP Setup Checklist


1. Choose an official or trusted MCP server.
2. Read its authentication and permission model.
3. Configure it using the current Codex documentation.
4. Authenticate through the provider's supported flow.
5. Inspect the available tools and start with read-only operations.
6. Test failure handling and access scope.
7. Recheck configuration after client updates.

A server connection grants tools; a skill provides workflow instructions. Neither should be treated as proof that every tool action is safe.
