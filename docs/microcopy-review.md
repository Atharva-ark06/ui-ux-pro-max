# Interface Microcopy Review

Good interface copy helps people predict outcomes, make informed choices, and recover from mistakes.

## Review questions
- **Clear:** Does the text use familiar words and name the action or outcome?
- **Concise:** Can any phrase be removed without losing necessary meaning?
- **Specific:** Do buttons say what will happen rather than using vague labels such as “Continue” when context is missing?
- **Consistent:** Are the same concepts and actions named consistently across the product?
- **Recoverable:** Do errors state what happened and how to proceed?
- **Honest:** Do confirmations, privacy notices, and progress messages accurately describe system behavior?

## Avoid
- Blaming the user for an error.
- Using color or icons as the only carrier of meaning.
- Promising a result the system cannot guarantee.
- Hiding fees, data use, or irreversible consequences behind ambiguous wording.

Read critical copy in context and test it with representative users when the decision is high impact.
