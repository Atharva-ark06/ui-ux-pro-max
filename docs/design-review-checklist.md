# Design Review Checklist

## Product and hierarchy
- [ ] Target user and primary task are clear.
- [ ] Main action is distinguishable from secondary actions.
- [ ] Content follows the order users need it.
- [ ] Claims and metrics have supporting evidence.

## Visual system
- [ ] Typography and spacing follow shared conventions.
- [ ] Color roles and component states are consistent.
- [ ] Text and meaningful non-text indicators have adequate contrast.
- [ ] Images have appropriate crop, size, and fallback behavior.

## Interaction and accessibility
- [ ] Keyboard users can reach and operate every control.
- [ ] Focus is visible and remains logical after state changes.
- [ ] Forms have labels, instructions, and recoverable errors.
- [ ] Loading, empty, disabled, success, and error states are considered.
- [ ] Motion respects user preferences.

## Responsive and release
- [ ] Narrow widths and zoom do not hide essential content.
- [ ] Long content and localized strings have been considered.
- [ ] Acceptance criteria and verification steps are documented.
- [ ] Untested areas and known limitations are recorded.
