# UX Metrics Selection Guide

Choose metrics that reflect a user outcome rather than collecting numbers because they are easy to track.

| User question | Candidate metric | Guardrail |
|---|---|---|
| Can users finish the task? | Task success rate | Define success before collecting data |
| How much friction occurs? | Time on task, error rate | Segment by task complexity |
| Where do users abandon? | Step-level completion | Funnel drop-off alone does not prove cause |
| Can users recover? | Recovery success after error | Track repeated failures and lost input |
| Is a change understood? | Comprehension or confidence test | Use neutral questions |
| Does a feature help? | Repeat use or task outcome | Clicks alone do not equal value |

## Good measurement practice
- Define event names and denominators consistently.
- Segment only where sample size and privacy allow.
- Pair quantitative signals with qualitative research.
- Record instrumentation gaps and known biases.
- Avoid collecting sensitive data unnecessarily.
- Use guardrail metrics to detect harm to other tasks.
