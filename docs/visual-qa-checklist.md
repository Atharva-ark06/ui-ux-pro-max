# Visual QA Checklist

## Layout
- [ ] Alignment and spacing follow shared patterns.
- [ ] No unintended overflow, clipping, overlap, or layout shift.
- [ ] Sticky elements do not cover content or focused controls.

## Type and assets
- [ ] Heading hierarchy and line height are readable.
- [ ] Long labels, translated strings, and validation messages fit.
- [ ] Images use the intended crop and have sensible fallbacks.
- [ ] Fonts load and fallback fonts remain usable.

## States
- [ ] Hover, focus-visible, active, disabled, and selected states work.
- [ ] Loading, empty, success, and error states are reviewed.
- [ ] Destructive actions communicate consequences.

## Responsive and accessibility
- [ ] Key breakpoints and short viewport heights are checked.
- [ ] Keyboard navigation and focus order remain logical.
- [ ] Contrast and non-color cues are reviewed.
- [ ] Reduced-motion behavior is checked.

Record browser, viewport, reproduction steps, expected result, actual result, and evidence for each defect.
