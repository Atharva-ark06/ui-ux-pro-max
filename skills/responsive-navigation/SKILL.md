# Responsive Navigation
1. List high-frequency destinations and keep them easy to reach.
2. Collapse navigation when available space or label length requires it.
3. Use a clearly named menu control and expose expanded/collapsed state.
4. Ensure opening and closing works with keyboard and touch.
5. Keep focus predictable and prevent menus from being clipped by viewport edges.
6. Preserve current-location indicators and useful breadcrumbs.
7. Avoid hiding essential actions in deep overflow menus.
8. Test long labels, zoom, short viewports, and screen-reader announcements.
