# Content Design
1. Identify what the user needs to know or decide at each step.
2. Organize information in the order users need it, not the order it was produced.
3. Put consequential facts before optional detail.
4. Use descriptive headings and scannable lists for complex information.
5. Explain unfamiliar terms at first use and keep labels consistent.
6. Pair claims with evidence or context when trust matters.
7. Review content at small widths and with assistive technology.
8. Remove repeated explanations that add length without improving understanding.
