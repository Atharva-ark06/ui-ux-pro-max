# Authentication UX
1. Make available sign-in methods and account requirements clear.
2. Use persistent labels and appropriate input types for credentials.
3. Explain password rules before submission and avoid needlessly restrictive policies.
4. Provide recovery paths that do not reveal whether a sensitive account exists.
5. Keep multi-factor steps understandable and explain recovery-code storage safely.
6. Prevent duplicate requests and preserve safe state during errors.
7. Avoid logging or displaying secrets in error messages.
8. Test keyboard navigation, password managers, mobile input, expired sessions, and recovery.
