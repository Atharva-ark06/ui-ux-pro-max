# Onboarding
1. Define the first meaningful outcome that demonstrates product value.
2. Ask only for information needed before that outcome; defer optional setup.
3. Explain why a permission or integration is needed before requesting it.
4. Use progressive disclosure instead of presenting every feature at once.
5. Provide a visible skip or later option when onboarding is not mandatory.
6. Make progress and next steps clear, and avoid false urgency.
7. Allow users to resume after interruption.
8. Measure completion and time-to-value, then test where users hesitate or abandon.
