# Design Handoff
1. State the user problem, intended outcome, and acceptance criteria.
2. Identify reusable components and tokens rather than specifying every repeated value separately.
3. Include responsive layouts and explain breakpoint behavior.
4. Document interaction triggers, transitions, validation, and error recovery.
5. Provide assets with appropriate formats, dimensions, naming, and licensing notes.
6. Record accessibility expectations for focus, labels, contrast, and keyboard behavior.
7. Describe edge cases such as empty content, long text, loading, and failure.
8. Agree on review ownership and compare the implementation against the handoff before release.
