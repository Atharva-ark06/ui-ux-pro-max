# Perceived Performance
1. Measure key user journeys, not only synthetic page-load scores.
2. Prioritize content needed for the first meaningful task.
3. Avoid layout shifts by reserving space for images, embeds, and asynchronous content.
4. Provide immediate feedback when an action starts.
5. Use optimistic updates only when rollback and failure states are safe and clear.
6. Keep long tasks cancellable when practical.
7. Test slow networks, cached versus uncached states, and lower-powered devices.
8. Report measured metrics separately from subjective impressions.
