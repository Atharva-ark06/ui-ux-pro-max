# Navigation Design
1. Inventory destinations and group them by user intent, not internal org chart.
2. Give each destination a concise, distinct label.
3. Prioritize frequent tasks; move rare actions to secondary navigation.
4. Show current location and preserve context in nested sections.
5. Define mobile behavior, keyboard order, active states, and overflow handling.
6. Avoid multiple competing navigation systems unless they serve different purposes.
7. Test with representative tasks: find a section, return home, and recover after a wrong turn.
## Validate
Track task completion, time-to-find, misclicks, and user vocabulary mismatches. Do not infer discoverability from visual neatness alone.
