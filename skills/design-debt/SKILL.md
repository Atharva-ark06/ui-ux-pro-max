# Design Debt Triage
1. Inventory repeated exceptions, duplicated styles, inaccessible states, and conflicting component patterns.
2. Record where each inconsistency appears and who it affects.
3. Separate visual preference from measurable usability, accessibility, or maintenance risk.
4. Estimate reach, severity, recurrence, and cost to fix.
5. Prioritize high-impact shared components before isolated cosmetic differences.
6. Document a migration path and compatibility needs.
7. Track accepted exceptions explicitly.
8. Verify cleanup improves consistency without unexpectedly changing intended behavior.
