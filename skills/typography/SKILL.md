# Interface Typography
1. Choose typefaces based on legibility, language coverage, loading cost, and product tone.
2. Define roles for display, heading, body, label, and supporting text.
3. Specify size, weight, line height, and letter spacing as a coherent scale.
4. Keep body line length comfortable and avoid overly tight line heights.
5. Check text at zoomed sizes and on narrow viewports.
6. Ensure hierarchy does not depend on size alone; use spacing and semantic headings too.
7. Test fallback fonts and long localized strings.
8. Verify contrast and avoid using low-contrast small text for essential information.
