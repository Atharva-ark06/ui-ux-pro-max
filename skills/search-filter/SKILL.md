# Search and Filtering
1. Identify whether users search known items, explore a catalog, or filter a dataset.
2. Use language that matches the user's vocabulary and support useful synonyms when available.
3. Decide when search runs: submit, debounce, or local filtering; make the behavior predictable.
4. Display active filters and provide clear removal/reset behavior.
5. Preserve query and filter state when opening a result and returning.
6. Distinguish no results from loading, errors, and empty datasets.
7. Announce result-count changes accessibly and avoid disruptive focus jumps.
8. Test zero matches, special characters, slow responses, and combined filters.
