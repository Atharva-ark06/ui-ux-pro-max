# Design QA
Check:
- Layout alignment, spacing rhythm, and consistent component sizing.
- Typography hierarchy, line length, wrapping, and truncation.
- Contrast, borders, focus indicators, and non-color status cues.
- Hover, focus, active, disabled, loading, success, and error states.
- Responsive behavior around breakpoints and on short viewports.
- Realistic content, empty data, long labels, and validation messages.
- Keyboard navigation and focus order after dynamic updates.
- Image crop, loading, and broken-asset fallbacks.
Record issue, screenshot or reproduction steps, severity, expected result, and owner. Verify fixes in the actual rendered interface; do not mark untested cases as passed.
