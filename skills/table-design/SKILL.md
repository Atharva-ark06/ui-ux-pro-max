# Table Design
1. Use clear column labels with units or definitions where needed.
2. Align values by type and use consistent formatting for dates, currency, and quantities.
3. Indicate sortable columns and current sort direction accessibly.
4. Keep row actions discoverable without overwhelming the primary data.
5. Provide empty, loading, error, and no-match states.
6. Decide intentionally between horizontal scrolling, column prioritization, and alternate mobile presentation.
7. Preserve header context for long tables and make selection state clear.
8. Test keyboard navigation, zoom, long cell content, and screen-reader table semantics.
