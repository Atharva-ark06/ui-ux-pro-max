# Privacy and Consent UX
1. Explain what data is collected, why, and which parties receive it.
2. Separate necessary processing from optional analytics or marketing choices.
3. Use equally understandable controls for accepting and declining optional uses.
4. Avoid preselected optional consent where it undermines meaningful choice or violates applicable rules.
5. Explain how preferences can be changed later.
6. Request permissions when the need becomes relevant.
7. Avoid dark patterns, false urgency, or ambiguous button labels.
8. Validate with privacy/legal stakeholders for the applicable jurisdiction; this guide is not legal advice.
