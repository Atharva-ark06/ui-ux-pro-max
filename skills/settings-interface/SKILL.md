# Settings Interface
1. Group options by user intent and use labels that describe the actual outcome.
2. Distinguish immediate changes from changes that require saving.
3. Show confirmation and current state for toggles and preferences.
4. Explain consequences before account deletion, data export, or security-sensitive changes.
5. Keep recovery and undo options available when possible.
6. Separate high-impact actions from routine preferences.
7. Ensure keyboard and screen-reader users can identify current values and status.
8. Test long labels, small screens, unsaved changes, and permission restrictions.
