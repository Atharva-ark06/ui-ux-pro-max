# Heuristic Evaluation
Review the interface for:
- Visibility of system status.
- Match between system language and user expectations.
- User control, undo, and safe exits.
- Consistency and established conventions.
- Prevention of errors before recovery is needed.
- Recognition rather than memory.
- Efficiency for both new and experienced users.
- Minimal, task-focused presentation.
- Clear diagnosis and recovery from errors.
- Helpful documentation when needed.
For each finding, include evidence, affected task, severity, and recommendation. Heuristics guide inspection; they do not replace testing with real users.
