# Dashboard Design
1. Identify the user's role, recurring questions, and decisions the dashboard supports.
2. Prioritize a small set of decision-driving metrics; explain definitions and time windows.
3. Show comparison context such as prior period, target, or meaningful benchmark.
4. Group related information and make drill-down paths predictable.
5. Avoid charts that duplicate the same signal without adding context.
6. Provide refresh timestamps, loading states, and clear treatment of stale or missing data.
7. Make filters visible and preserve them during navigation where useful.
8. Check keyboard access, contrast, mobile layout, and dense-data readability.
