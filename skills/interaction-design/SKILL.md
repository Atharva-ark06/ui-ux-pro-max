# Interaction Design
1. Define the trigger, state transition, result, and any side effect for each interaction.
2. Make affordances and available actions visible.
3. Provide immediate feedback for activation and clear completion feedback for asynchronous work.
4. Keep focus stable and logical after dialogs, menus, and route changes.
5. Support keyboard and pointer interaction without relying on hover alone.
6. Prevent accidental destructive actions and provide undo when feasible.
7. Specify disabled states and explain unavailable actions where users need that context.
8. Test rapid clicks, slow networks, repeated submissions, and interrupted flows.
