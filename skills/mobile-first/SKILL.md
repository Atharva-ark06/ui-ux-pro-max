# Mobile-First Interface Workflow
1. Prioritize the core task and essential content before arranging secondary features.
2. Start with a single-column reading and interaction flow.
3. Use fluid dimensions and add layout complexity when content has room.
4. Keep tap targets distinct, reachable, and separated from destructive actions.
5. Consider virtual keyboards, safe areas, orientation, and reduced viewport height.
6. Avoid hover-only instructions and tiny controls.
7. Test slow connections, long text, zoom, and touch plus keyboard input.
8. Add larger-screen enhancements without creating a separate, inconsistent product experience.
