# Form Design
1. Identify the smallest set of information needed to complete the task.
2. Group related fields and order them in the user's natural sequence.
3. Use persistent labels; placeholders are examples, not replacements for labels.
4. Explain required formats before submission and use appropriate input types.
5. Validate at the right time; preserve valid input after errors.
6. Associate errors with fields and summarize multiple errors when useful.
7. Show progress for long or multi-step forms and explain why sensitive data is needed.
8. Test keyboard operation, zoom, mobile keyboards, and long error messages.
## Review checklist
- Can users tell what each field expects?
- Are optional and required fields clear?
- Can users correct errors without losing work?
- Is the next action clear before and after submission?
