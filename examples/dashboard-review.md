# Example: Dashboard Review

This is a hypothetical review aid, not a claim about a specific dashboard.

## Review questions
- Can the intended user identify the most important metric quickly?
- Are units, date ranges, and metric definitions visible?
- Is each comparison grounded in a meaningful baseline or target?
- Are missing, stale, and zero values distinguishable?
- Do filters explain which data is currently shown?
- Can users reach detailed records from summary metrics?
- Are charts labeled accessibly and understandable without color alone?
- Do loading, empty, error, and narrow-screen states work?

## Prioritization
Treat misleading metrics, stale-data ambiguity, and inaccessible key actions as high-impact risks. Record evidence and a verification plan for each finding.
